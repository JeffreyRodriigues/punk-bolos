## O que o usuário pediu

Olá! Quero criar um sistema de gerenciamento de pedidos para a minha confeitaria, a **"Punk Bolos"**.

Quero algo simples e sem frameworks, usando apenas **HTML, CSS e JavaScript puros**. O sistema deve me ajudar a controlar os pedidos dos clientes.

Funcionalidades que imagino:

- Cadastro de pedidos com nome do cliente, contato, tipo de produto (**fatia, punkitos, bolo inteiro**), **sabores**, quantidade, valor e observações.
- Controle de **status** do pedido com o fluxo de produção (**pendente, em produção, embalado, concluído, cancelado**).
- Uma **tela inicial** com o resumo das vendas: receita, quantidade de pedidos, pendentes, embalados, concluídos, quantidade de fatias/bolos/punkitos e **ticket médio**.
- Uma **lista de pedidos** com busca e filtros.
- Dados salvos **no navegador** (LocalStorage), sem precisar de banco de dados.
- **Modo claro e escuro**.
- Que funcione bem no **celular e no computador** (responsivo).

Por favor, me ajude a construir **por etapas**, validando cada etapa comigo antes de avançar para a próxima.

---

## Decisões alinhadas na sequência (resumo)

- Papéis: eu (usuário) como **Arquiteto de Software**; você como **Desenvolvedor Full Stack Sênior**.
- Entrega **uma etapa por vez**, com testes antes de seguir.
- Stack aprovado: **HTML5 + CSS3 + JavaScript ES6+ (módulos)**, LocalStorage, **sem frameworks**; Chart.js apenas se solicitado.
- Posteriormente evoluído para **múltiplos produtos por pedido** e **filtro por período de datas** (ver `FUNCIONALIDADES.md` e `MELHORIAS.md`).
